# Knock Knock Delivery - Initial Scaffold

This repository contains the initial scaffold for Knock Knock Delivery Service Sargodha.

What’s included in this commit (minimal, production-oriented scaffold):

- Frontend: Next.js (App Router) + TypeScript + Tailwind + React Three Fiber placeholder
- Backend: Express + TypeScript + Mongoose + Socket.io stub
- Core Mongoose models: User, Product, Order, DeliveryRequest
- Seed script to populate demo data
- .env.example with placeholders
- README with setup instructions

Notes
- This is a starter scaffold to accelerate development. Replace placeholder keys in .env and add assets (GLTF models, images) to web/public.
- For production, secure secrets in your provider, configure CORS, HTTPS, and CI/CD.
